# Triage

Use the configured issue tracker to classify and advance incoming issues or external pull requests. Every posted comment or issue must start with:

```text
> *This was generated by AI during triage.*
```

If the tracker or triage-label mapping is not configured, run `/setup-matt-pocock-skills` before changing tracker state.

Read [TRIAGE-MODEL.md](TRIAGE-MODEL.md), then load only the mode that matches the request:

- Show work needing attention → [TRIAGE-LIST.md](TRIAGE-LIST.md)
- Triage a named issue or PR → [TRIAGE-ITEM.md](TRIAGE-ITEM.md)
- Apply an explicit state change → [TRIAGE-OVERRIDE.md](TRIAGE-OVERRIDE.md)
- Resume work with prior notes → [TRIAGE-RESUME.md](TRIAGE-RESUME.md)

Load [AGENT-BRIEF.md](AGENT-BRIEF.md) when writing a ready-for-agent brief and [OUT-OF-SCOPE.md](OUT-OF-SCOPE.md) when evaluating a rejected enhancement.
