# Explicit state changes

When the maintainer explicitly names the issue or PR and the target state, apply that state directly and report the change. Do not ask for a second confirmation of a clear command.

Ask only when the target, role, or requested comment/close action is ambiguous, or when existing labels conflict in a way that changes the outcome. If the maintainer moves an item to `ready-for-agent` without a grilling session, offer to write an agent brief after applying the requested state; do not block the state change on that offer.
