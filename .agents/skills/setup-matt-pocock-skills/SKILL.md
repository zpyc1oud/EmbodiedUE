# Setup Matt Pocock's Skills

Run this once when the repository has not configured the engineering skills. Start with [SETUP-FLOW.md](SETUP-FLOW.md), then load only the branches that apply:

- Issue tracker → [ISSUE-TRACKER-SETUP.md](ISSUE-TRACKER-SETUP.md)
- Triage labels → [TRIAGE-LABEL-SETUP.md](TRIAGE-LABEL-SETUP.md), only when `/triage` is installed
- Domain documents → [DOMAIN-DOCS-SETUP.md](DOMAIN-DOCS-SETUP.md)

The branch documents point to the existing GitHub, GitLab, local-markdown, label, and domain templates. Present a concrete draft before writing it, preserve surrounding user edits, and report which engineering skills will use the configuration afterward.
