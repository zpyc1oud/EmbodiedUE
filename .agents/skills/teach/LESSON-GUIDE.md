# Lesson guide

A lesson teaches one tightly scoped skill tied to the mission and gives the user one tangible win. Keep it short enough to complete quickly, use high-trust resources, and put only the knowledge needed for the skill in the lesson.

Save it as a self-contained HTML file under `lessons/`. Use clear, readable layout, link related lessons and reference documents, recommend the strongest primary source, and invite follow-up questions. Open the file when useful.

Teach knowledge directly, then let the user practise through an interactive feedback loop. Use retrieval practice, spacing, and interleaving when they fit the topic. For quizzes, keep answer choices comparable and avoid revealing the answer through formatting.

Create or update a compact reference document when the lesson produces reusable knowledge such as syntax, algorithms, routines, or a glossary. Record what the lesson settled in a learning record when the user demonstrates genuine understanding, discloses prior knowledge, corrects a misconception, or changes the mission.
