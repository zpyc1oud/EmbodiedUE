# Resources and wisdom guide

Use `RESOURCES.md` to curate high-trust knowledge sources and communities. Prefer primary sources, recognized experts, peer-reviewed work, and well-moderated communities. Annotate each entry with what it covers and when to use it; record gaps when the mission has no suitable source.

Knowledge comes from sources and supports explainers. Wisdom comes from real-world practice. When a question needs wisdom, answer as far as evidence allows and point the user toward a reputable community or practice setting. Respect a user's preference not to join a community and record that preference for later sessions.

Prune sources that are wrong, shallow, or off-mission. Keep the resource list useful rather than exhaustive.
