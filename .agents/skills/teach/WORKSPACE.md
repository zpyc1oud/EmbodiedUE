# Teaching workspace

The current directory stores the user's learning state:

- `MISSION.md` — why the user is learning and what success looks like.
- `RESOURCES.md` — trusted knowledge sources and communities.
- `reference/*.html` — compact reference material.
- `lessons/*.html` — self-contained lessons, numbered `0001-<dash-case-name>.html`.
- `learning-records/*.md` — non-obvious lessons and established prior knowledge, numbered sequentially.
- `assets/*` — reusable lesson components.
- `NOTES.md` — teaching preferences and working notes.

Create directories and files lazily. Before authoring a lesson, inspect existing assets and reuse shared components; add a component when a second lesson could reuse it. Keep lessons and reference documents linked so the workspace remains navigable.
