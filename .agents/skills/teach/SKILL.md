# Teach

This is a stateful, multi-session teaching workspace. Read [WORKSPACE.md](WORKSPACE.md) for the artifact map, then load only the guide for the requested work:

- Create or revise a lesson → [LESSON-GUIDE.md](LESSON-GUIDE.md)
- Clarify the mission or choose the next challenge → [MISSION-GUIDE.md](MISSION-GUIDE.md)
- Curate sources or handle a wisdom question → [RESOURCES-GUIDE.md](RESOURCES-GUIDE.md)
- Record learned terminology → [GLOSSARY-FORMAT.md](GLOSSARY-FORMAT.md)
- Record a durable learning insight → [LEARNING-RECORD-FORMAT.md](LEARNING-RECORD-FORMAT.md)

Use the existing format files for the corresponding artifact. Keep every lesson tied to the mission and leave the workspace ready for the next session.
