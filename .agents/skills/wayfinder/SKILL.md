# Wayfinder

Use this planning flow when a large effort is still too unclear to turn directly into implementation work. The map resolves decisions toward a named destination; it does not deliver the destination unless the map's notes explicitly include execution.

Load the branch that applies:

- Map structure, claims, blocking, and resolution → [MAP-REFERENCE.md](MAP-REFERENCE.md)
- Ticket categories → [TICKET-TYPES.md](TICKET-TYPES.md)
- Loose idea with no map → [CHART-MODE.md](CHART-MODE.md)
- Existing map → [WORK-MODE.md](WORK-MODE.md)
- Unclear scope or newly surfaced work → [FOG-AND-SCOPE.md](FOG-AND-SCOPE.md)

Use the configured issue-tracker operations from `docs/agents/issue-tracker.md`. Size work around one coherent decision and its evidence; split or parallelize when dependencies, risk, or collaboration make that useful. Claim a ticket before changing it.
