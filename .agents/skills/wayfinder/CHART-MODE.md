# Chart mode

Use this mode when the user has a loose idea and no map.

- Name the destination with `/grilling` and `/domain-modeling`.
- Survey the frontier breadth-first so the open decisions and immediately researchable questions are visible. If the route is already clear, use the ordinary planning flow instead of creating a map.
- Create the map, record its Notes, sketch the fog, and create the decision tickets that are sharp enough now. Wire their blocking edges after the ticket ids exist.
- Start `/research` for research tickets when useful, linking the findings from each ticket.

Charting records the route. Work through the tickets in [WORK-MODE.md](WORK-MODE.md) when the user wants decisions resolved.
