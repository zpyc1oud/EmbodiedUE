# Work mode

Use this mode when the user provides an existing map.

- Load the map's low-resolution index first. Fetch related ticket bodies only when their detail is needed.
- Use the ticket the user named; otherwise choose an open, unblocked, unclaimed frontier ticket. Claim it before work.
- Resolve the decision using the skills named in the map's Notes. Use `/grilling` and `/domain-modeling` when the route needs a human decision.
- Record the answer as a resolution comment, close the ticket, and append its gist and link to Decisions so far.
- Create and wire newly sharp tickets, graduate resolved fog, and update or close tickets invalidated by the decision.

Unblocked tickets can be worked in parallel by other sessions, so expect the tracker to change while the map is active.
